¿Qué es?

    Aircrack-ng es una suite de herramientas de auditoría de redes inalámbricas (WiFi), enfocada en la seguridad de redes IEEE 802.11 (WEP, WPA, WPA2, WPA3 preliminar).
    
    No es una sola herramienta, sino un conjunto que permite:
    
        > Capturar tráfico inalámbrico
        > Inyectar paquetes
        > Realizar ataques de autenticación
        > Probar la seguridad de claves WiFi
        > Descubrir vulnerabilidades en configuraciones de redes
    
    Se usa en pentesting, hacking ético y ciberseguridad defensiva para verificar la fortaleza de redes WiFi.
	
	
¿Para qué se usa?

    1. Auditoría de seguridad WiFi: comprobar si las contraseñas WEP/WPA/WPA2 son robustas.
    2. Captura de handshakes: necesarios para romper contraseñas WPA/WPA2.
    3. Inyección de tráfico: simular ataques (ej: deauthentication attack).
    4. Sniffing: analizar tráfico en vivo.
    5. Fuerza bruta y diccionarios: probar claves contra el handshake capturado.
    6. Análisis de rendimiento de la tarjeta WiFi.	
	
	
Componentes principales de Aircrack-ng

    ---------------------------------------------------------------------------------------------------------------------------------------------------------
    |  Componente   |  Descripción                                                       |  Ejemplo de Uso                                                  |  
    ---------------------------------------------------------------------------------------------------------------------------------------------------------
    |  airmon-ng    |  Activa/desactiva el modo monitor en la tarjeta WiFi.              |  airmon-ng start wlan0                                           |
    |  airodump-ng  |  Captura paquetes de una red.                                      |  airodump-ng wlan0mon                                            |
    |  aireplay-ng  |  Inyecta tráfico (ej: deauth attack para desconectar clientes).    |  aireplay-ng --deauth 10 -a <MAC_AP> -c <MAC_CLIENTE> wlan0mon   |
    |  aircrack-ng  |  Rompe contraseñas WEP/WPA/WPA2 a partir de capturas.              |  aircrack-ng -w diccionario.txt -b <BSSID> captura.cap           |
    |  airbase-ng   |  Monta un AP falso (Evil Twin) para ataques de ingeniería social.  |  airbase-ng -e FakeWiFi -c 6 wlan0mon                            |
    |  airdecap-ng  |  Descifra paquetes capturados con claves conocidas.                |                                                                  |
    |  airserv-ng   |  Da acceso remoto a interfaces inalámbricas.                       |                                                                  |
    ---------------------------------------------------------------------------------------------------------------------------------------------------------	
	
	
Opciones más usadas

    --------------------------------------------------------------
    |  Opción       |  Descripción                               |
    --------------------------------------------------------------
    |  -w           |  especificar diccionario (wordlist).       |
    |  -b           |  indicar BSSID del AP objetivo.            |
    |  -c           |  indicar canal de la red.                  |
    |  --deauth     |  ataque de desautenticación.               |
    |  --fakeauth   |  autenticación falsa.                      |
    |  --arpreplay  |  reinyectar paquetes ARP (ataques WEP).	 |
    --------------------------------------------------------------	
	
Ejemplo típico de uso (auditoría WPA/WPA2)

    --------------------------------------------------------------------------------------------------------------------------------------------------
    |  Descripción                                                                         |  Ejemplo de Uso                                         |
    --------------------------------------------------------------------------------------------------------------------------------------------------
    |  Poner la tarjeta en modo monitor                                                    |  airmon-ng start wlan0                                  |      
    |  Escanear redes y elegir objetivo                                                    |  airodump-ng wlan0mon                                   |
    |  Capturar el handshake                                                               |  airodump-ng -c 6 --bssid <BSSID> -w captura wlan0mon   |
    |  Forzar desconexión de clientes (para que vuelvan a conectarse y generen handshake)  |  aireplay-ng --deauth 5 -a <BSSID> wlan0mon             |
    |  Romper la contraseña con un diccionario                                             |  aircrack-ng -w diccionario.txt -b <BSSID> captura.cap  |
    --------------------------------------------------------------------------------------------------------------------------------------------------


En resumen

    > Aircrack-ng Suite es un conjunto de herramientas para auditoría y pruebas de seguridad WiFi, usado tanto en pentesting ofensivo (ethical hacking) como en defensivo 
      (reforzar redes inalámbricas).
