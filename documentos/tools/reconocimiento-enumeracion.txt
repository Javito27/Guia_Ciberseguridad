> Es una herramienta de reconocimiento y análisis de seguridad que se utiliza principalmente para identificar relaciones y posibles rutas de ataque 
  dentro de entornos de Active Directory (AD). Fue desarrollada por los investigadores de seguridad de SpecterOps y es muy utilizada por equipos de

    |
    |> Instalación 
    |    |
    |    |> GUI - git clone https://github.com/SpecterOps/BloodHound

    |    |> CLI - git clone https://github.com/dirkjanm/BloodHound.py
    |        |
    |        |> sudo pip3 install . --break-system-packages
    |
    |

    |    |
    |    |> Usuarios
    |    |> Equipos (computadoras)
    |    |> Grupos
    |    |> Políticas delegadas 
    |    |> ACLs (Listas de Control de Acceso)
    |    |
    |    |> Luego construye un grafo de relaciones que permite visualizar cómo un atacante podría escalar privilegios o moverse lateralmente en la red.

    |    |
    |    |> Ingesta en la base de datos

    |    |    |> Los datos recolectados se cargan en la interfaz de BloodHound.
    |    |		
    |    |> Visualización de relaciones
    |    |    |
    |    |    |> Usando un grafo visual, se pueden ver rutas como
    |    |        |
    |    |        |> "Este usuario puede ejecutar código como admin en esta máquina."
    |    |        |> "Este grupo tiene derechos sobre este objeto."
    |    |    		
    |    |> Análisis de ataques potenciales

> Es una base de datos orientada a grafos, diseñada para almacenar, consultar y gestionar datos estructurados como nodos, relaciones y propiedades. A 
  diferencia de las bases de datos relacionales tradicionales (como MySQL o PostgreSQL), Neo4j está optimizada para representar y consultar relaciones 
  complejas entre datos de manera eficiente.

    |		
    |> Características principales	
    |         |

    |         |  relaciones entre nodos (como "amigo de", "compra", "trabaja en") son de primera clase, es decir, tan importantes como los 
    |         |  propios nodos.
    |         |	
    |         |> Consulta con Cypher: Usa su propio lenguaje de consulta llamado Cypher, diseñado específicamente para trabajar con grafos.

    |         |  recomendaciones, detección de fraudes, etc.

    |         |> ACID: Cumple con las propiedades ACID (Atomicidad, Consistencia, Aislamiento, Durabilidad), lo que garantiza la integridad

    |         |> Gestión de redes (IT, telecomunicaciones)

> Realiza fuerza bruta de rutas/directorios, subdominios, archivos y buckets S3 en servidores web.
> Enumera rutas/directorios
> Escrito en lenguaje Go
    |
    |> Que hace 
    |    |
    |    |> Descubrimiento de directorios y archivos.
    |    |> Enumeración de subdominios.
    |    |> Escaneo de buckets de Amazon S3 (modo s3).
    |    |> Fuerza de URIs en servidores DNS.
    |	
    |> Enumerar rutas / directorios
    |    |
    |    |> gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt
    |    |> gobuster dir -u http://<IP> -w /usr/share/wordlists/dirb/common.txt -x txt,rdp,php,asp
    |    |> gobuster dir -u http://<IP> -w /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt -t 50 --no-error
    |    |> gobuster dir --url http://<IP> --wordlist /usr/share/wordlists/dirb/big.txt
    |	
    |> Enumerar subdominios
    |    |
    |    |> gobuster vhost --append-domain -w /usr/share/wordlists/seclists/Discovery/DNS/subdomains-top1million-5000.txt -u http://<DOMAIN>
    |	
    |> Diccionarios	
    |    |
    |    |> /usr/share/seclists/Discovery/Web-Content/common.txt
    |    |> /usr/share/wordlists/dirb/common.txt
    |    |> /usr/share/seclists/Discovery/Web-Content/directory-list-2.3-medium.txt
    |	
    |> Parámetros útiles
         |
         |> URL objetivo > -u
         |> Ruta del diccionario (wordlist) > -w
         |> Número de hilos (threads) > -t 
         |> Extensiones de archivo > -x
         |> Para ignorar subdominios con wildcard DNS > --wildcard
         |> Para evitar errores > --no-error

> Parabuster es una herramienta de fuerza bruta utilizada comúnmente para descubrir directorios y archivos ocultos en servidores web. Es similar a 
  otras herramientas como DirBuster, Gobuster o Dirsearch, y suele emplearse en pruebas de penetración y evaluaciones de seguridad para encontrar 
  rutas no protegidas o mal configuradas.
    |
    |> Características principales de Parabuster:
    |    |
    |    |> Fuerza bruta de rutas: Utiliza diccionarios de palabras (wordlists) para probar diferentes 
    |    |  combinaciones de nombres de archivos y directorios.
    |    |
    |    |> Soporte para HTTP/S: Funciona tanto con sitios HTTP como HTTPS.
    |    | 
    |    |> Multihilo: Puede realizar múltiples solicitudes simultáneamente para acelerar la búsqueda.
    |    | 
    |    |> Filtros de respuestas: Permite ignorar respuestas con ciertos códigos HTTP (como 404 o 403) 
    |       o tamaños de respuesta.
    |
    |> Usos comunes
    |    |
    |    |> Descubrir rutas ocultas (como /admin, /login, /backup, etc.).
    |    |> Identificar puntos débiles o mal configurados en una aplicación web.
    |    |> Obtener una mayor superficie de ataque en pruebas de penetración.
    |
    |> Ejemplo de uso típico (en línea de comandos)
         |
         |> parabuster -u https://ejemplo.com -w /ruta/a/wordlist.txt

> Es una herramienta de línea de comandos muy utilizada para capturar y analizar tráfico de red. 
> Permite inspeccionar paquetes que pasan por una interfaz de red, lo cual es útil para diversas tareas. 
    |
    |> Tareas 
    |    |> Diagnóstico de red.
    |    |> Análisis de rendimiento.
    |    |> Detección de actividades sospechosas o maliciosas.
    |    |> Auditorías de seguridad.
    |
    |> Características clave
    |    |
    |    |> Captura en tiempo real: muestra los paquetes a medida que llegan.
    |    |> Filtros BPF (Berkeley Packet Filter): permite seleccionar solo ciertos tipos de tráfico (por ejemplo, solo paquetes TCP o de una IP específica).
    |    |> Exportación a archivos: puede guardar las capturas en formato .pcap para analizarlas luego con herramientas como Wireshark.
    |
    |> Donde se utiliza
    |    |
    |    |> En entornos de administración de sistemas y redes
    |    |> En análisis forense digital
    |    |> Por investigadores de seguridad y pentesters
    |
    |> Ejemplo básico de uso > sudo tcpdump -i eth0
    |	
    |> Ejemplo con filtro > sudo tcpdump -i eth0 tcp port 80
    |
    |> Comandos
         |
         |> Indicar la interfaz de red > tcpdump -i eth0
         |
         |> Para volcar datos > tcpdump -i eth0 -w file.pcap
         |
         |> Se interpretan los bytes >  tcpdump -i eth0 -A
         |
         |> Imprime en formato hexadecimal >  tcpdump -i eth0 -XX
         |
         |> Filtro en función de lo que ponga > tcpdump -i eth0 tcp
         |
         |> tcpdump -i eth0 tcp port xx
