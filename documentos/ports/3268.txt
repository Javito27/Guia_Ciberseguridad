📌 Es utilizado por el Global Catalog (GC) en Active Directory.

    Se utiliza para consultar, modificar y buscar información en directorios distribuidos y centrales, siguiendo el modelo cliente-servidor.

    El Global Catalog es un servicio especial dentro de un Domain Controller que:

        · Contiene una copia parcial de todos los objetos del bosque (forest)
        · Permite búsquedas rápidas en múltiples dominios
        · Facilita la autenticación en entornos con varios dominios
        · Consulta datos en Active Directory, como usuarios, grupos y políticas.

    Es como una “vista resumida” de todo el bosque de Active Directory.

⚙️ ¿Qué hace el puerto 3268?

    Funciona similar a LDAP (389), pero:

        🔎 Permite búsquedas en todo el bosque
        👥 Responde consultas más amplias
        🌐 Se usa cuando hay múltiples dominios

    Importante:

        3268 → GC sin cifrar
        3269 → GC cifrado (SSL/TLS)

🧪 En pentesting

    Si el 3268 está abierto:

        · Indica que el DC tiene rol de Global Catalog
        · Permite enumeración amplia de objetos
        · Puede revelar usuarios de otros dominios
        · Útil para reconocimiento en entornos grandes

🔐 Riesgos

    · Enumeración masiva de usuarios
    · Obtención de información para ataques Kerberoasting
    · Mapeo completo del entorno AD

🎯 Ejemplo de uso básico

    ldapsearch -x -H ldap://<IP> -b "dc=DOMINIO, dc=COM, ES, ORG, ETC..."

    Donde: 

        ldapsearch  →   Herramienta para consultar LDAP
        -x  →   Autenticación simple (sin SASL)
        -H  →   ldap://IP	Dirección del servidor LDAP
        -b  →   Base DN (punto desde donde empieza la búsqueda)
        "dc=empresa,dc=local"   →   Dominio en formato LDAP
