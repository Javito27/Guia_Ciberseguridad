📌 Es la versión cifrada (SSL/TLS) del Global Catalog en Active Directory. Es el equivalente seguro de:

    3268 → Global Catalog sin cifrar
    3269 → Global Catalog cifrado

    En Active Directory, el Global Catalog (GC):

        · Contiene una copia parcial de todos los objetos del bosque
        · Permite búsquedas en múltiples dominios
        · Se usa en autenticaciones y consultas globales

⚙️ ¿Qué hace el puerto 3269?

    1️⃣ Cliente conecta al DC por el 3269
    2️⃣ Se establece handshake TLS
    3️⃣ Se cifra la comunicación
    4️⃣ Se realizan búsquedas LDAP a nivel de bosque

🧪 En pentesting

    Si el 3269 está abierto:

        Indica Domain Controller con GC habilitado
        Permite enumeración amplia pero cifrada
        Se analiza certificado TLS
        Se revisa configuración segura

🔐 ¿Es peligroso?

    No por sí mismo.
    Pero puede permitir:

        · Enumeración masiva si hay credenciales válidas
        · Información estructural del dominio
        · Preparación para ataques AD

🎯 Ejemplo de uso básico

    ldapsearch -x -H ldap://<IP> -b "dc=DOMINIO, dc=COM, ES, ORG, ETC..."

    Donde: 

        ldapsearch  →   Herramienta para consultar LDAP
        -x  →   Autenticación simple (sin SASL)
        -H  →   ldap://IP	Dirección del servidor LDAP
        -b  →   Base DN (punto desde donde empieza la búsqueda)
        "dc=empresa,dc=local"   →   Dominio en formato LDAP
