➡️ This lab contains a SQL injection vulnerability in the product category filter.

The results from the query are returned in the application's response, so you can use a UNION attack to retrieve data from other tables. 

To construct such an attack, you first need to determine the number of columns returned by the query. 

You can do this using a technique you learned in a previous lab. The next step is to identify a column that is compatible with string data.

The lab will provide a random value that you need to make appear within the query results. 

To solve the lab, perform a SQL injection UNION attack that returns an additional row containing the value provided. 

This technique helps you determine which columns are compatible with string data. 


🎯 SOLUCIÓN DEL LABORATORIO

    1️⃣ Seleccionar FoxyProxy

        En el navegador seleccionamos la opción BURP en FoxyProxy para que BurpSuite intercepte las peticiones. 

    2️⃣ Abrir BurpSuite

        Se abre BurpSuite y vamos a Proxy > HTTP history

    3️⃣ Para determinar el numero de columnas que devuelve la consulta y cuáles contienen datos de texto, hay que realizar la siguiente request: 

        · Seleccionamos una categoría, por ejemplo all
        · En HTTP History buscamos la request y la enviamos a Repeater para modificar la request
        · En el parámetro category, se sustituye por el siguiente payload: 

            '+UNION+SELECT+NULL,NULL,NULL--

        · Esa query comprueba cuántas columnas tiene la consulta original, probando con 3 columnas de tipo NULL.


    4️⃣ Usar una inyección SQL para que devuelva una fila adicional que contenga el valor determinado

        · Esto sirve para determinar qué columnas son compatibles con los datos de cadena. Se usa el siguiente payload: 

            '+UNION+SELECT+NULL,'abcdef',NULL--
    
        · Se va sustituyendo NULL por un valor que deseemos. 

    5️⃣ Para resolver el laboratorio, hay que sustituir la cadena anterior, por la que encontramos en la response: 

        Make the database retrieve the string: 'ILLIhR'

        · Usando el siguiente payload: 

            '+UNION+SELECT+NULL,'ILLIhR',NULL--
